Конфликт слияния (merge conflict) — это ситуация в Git, при которой система не может автоматически объединить изменения из двух веток и требует вмешательства разработчика. В моём случае он возник из-за того, что в обеих ветках были независимо отредактированы одни и те же строки в файле Main.java. Для разрешения конфликта я вручную удалил маркеры конфликта (<<<<<<<, =======, >>>>>>>) и оставил корректную итоговую версию кода. Затем я проиндексировал обновлённый файл командой git add Main.java и зафиксировал результат слияния с помощью git commit
